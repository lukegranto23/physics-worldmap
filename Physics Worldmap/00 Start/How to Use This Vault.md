# How to Use This Vault

This vault is a **map, memory system, laboratory, and research notebook**. It is intentionally layered:

1. **Maps of content** answer “where does this idea live?”
2. **Atomic concept notes** answer “what is the minimal durable idea?”
3. **Deep dives and derivations** answer “why is it true and when does it fail?”
4. **Experiment notes** answer “what observation supports the claim?”
5. **Computational labs** answer “can I reproduce the behavior?”
6. **Frontier notes** answer “what is known, disputed, or missing?”
7. **Synthesis notes** answer “which structures transfer, and what would test the transfer?”

## Recommended Obsidian workflow

- Pin [[Physics Worldmap]] and [[Learning Paths]].
- Use Local Graph depth 2 while reading a concept.
- Add `#review/due` only when a note has a concrete recall question.
- Use backlinks to inspect where a concept is applied.
- Put personal annotations below a `## My reconstruction` heading rather than altering evidence summaries invisibly.
- Never move an item from `open` to `established` without updating its source trail.

## A note is “learned” only when

- You can define its objects and observables in plain language.
- You can reconstruct the central equation or argument.
- You can name its assumptions and at least one failure regime.
- You can connect it to evidence.
- You can solve or simulate a representative case.
- You can distinguish it from its nearest conceptual neighbor.
