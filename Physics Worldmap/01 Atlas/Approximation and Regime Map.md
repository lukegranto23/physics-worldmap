# Approximation and Regime Map

| Approximation | Control parameter or condition | Connects |
|---|---|---|
| nonrelativistic | $v/c\ll1$ and weak fields | relativity → Newtonian mechanics |
| classical | action scales $\gg\hbar$, decoherence, coarse observables | quantum → classical |
| geometric optics | $\lambda/L\ll1$ | waves → rays |
| continuum | microscopic length / system length $\ll1$ | particles → fields |
| ideal gas | low density and weak correlations | interacting matter → independent particles |
| linear response | perturbation small enough for first order | equilibrium fluctuations → response |
| adiabatic | drive slow relative to gaps or relaxation | time-dependent → quasistatic |
| Born-Oppenheimer | nuclear/electronic timescale separation | molecular → electronic surfaces |
| weak field gravity | $GM/(Rc^2)\ll1$ | GR → Newtonian or post-Newtonian gravity |
| MHD | scales larger than kinetic scales with suitable closure | kinetic plasma → conducting fluid |
| thermodynamic limit | $N,V\to\infty$ at fixed density | finite systems → sharp phases |
| effective field theory | $E/\Lambda\ll1$ | high-energy completion → low-energy operators |

For every approximation record: **small parameter, retained order, error estimate, boundary layer or singular limit, and failure observable**.
