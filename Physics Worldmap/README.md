# Physics Worldmap

Open this folder as an Obsidian vault:

1. In Obsidian, choose **Open folder as vault**.
2. Select the `Physics Worldmap` folder.
3. Open `Physics Worldmap.md` or the bookmarked spatial Canvas. Inside Obsidian, `[[Physics Worldmap.canvas]]` is the direct Canvas target.

The vault distinguishes established results, effective models, active research, open questions, and speculative synthesis. It is built to be extended: templates live in `99 Templates`, code labs in `62 Computational Labs`, and current frontier audits in `80 Frontiers`.

No community plugin is required. Core Graph, Canvas, Backlinks, Properties, Templates, and Bookmarks are configured.

The Python labs use NumPy and Matplotlib. From `62 Computational Labs`, install `requirements.txt`, then run `python run_all.py --quick`. Validated example results are already included in the lab gallery.

Use `95 Resources/Vault Health Report.md` to inspect the most recent structural audit.

Read `95 Resources/Release Status and Next Work.md` before treating this as a finished reference. Most concept notes are orientation stubs awaiting deeper source audits. Labs 14–16 are exploratory programs, excluded from the core runner; their execution does not validate new physics.
