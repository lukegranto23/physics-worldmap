# Spontaneous Symmetry Breaking

> [!summary] Core idea
> For a physical global symmetry, a symmetric dynamics can have asymmetric stable states, producing order parameters and—when a continuous global symmetry is broken—Goldstone modes. Local gauge symmetry is a redundancy, so its “breaking” requires gauge-fixed language or a gauge-invariant Higgs-phase description.

> [!caution] Orientation status
> This is a compact orientation note and has not yet been source-audited. The epistemic label describes the standing of the underlying physics in its stated regime; it does not certify every sentence or equation in this note.

## Mathematical handle

$\langle\mathcal O\rangle\ne0$ for a symmetry-transforming, gauge-invariant order parameter $\mathcal O$

For global symmetries this expectation value can distinguish symmetry-related phases, subject to finite-volume and dimensional caveats. A gauge-variant field expectation value is not itself an observable: Elitzur's theorem forbids spontaneous breaking of an unfixed local gauge redundancy. The Higgs mechanism is therefore stated through gauge-invariant observables or, more conveniently but less literally, in a chosen gauge.
